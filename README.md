# Printwright bug reports and feedback

This repository is for bug reports and feature requests for Printwright, a desktop 3D-printing workbench. It has no source code.

## Reporting from inside Printwright

The easiest way is from the app: click the speech-bubble button in the toolbar, or search for "Report a bug" with Ctrl/Cmd+K. Printwright fills in the issue for you, including diagnostics and a debug report with paths and names removed. You review it here and press Submit. If the app saved a `printwright-debug-*.json` file to your Downloads folder, drag it into the Attachments box.

From the command line: `printwright feedback bug -t "Short title" -d "What happened" --open`.

## How to file a good report

Open a [new issue](https://github.com/DarrellBest-Org/printwright-issues/issues/new/choose) and include:

- The Printwright version
- Your operating system (Windows, macOS, or Linux)
- The tool you were using and its parameters, if relevant
- The steps that led to the problem
- What you expected, and what actually happened
- Screenshots, and the model or exported file if you can share it

Do not include passwords or payment details.
